# Showcase photos

Drop your "life" photos here, then update the matching card in `_showcase/life/`.

Suggested filenames (referenced by the scaffold cards):

- `candid.jpg`            — a casual portrait for the intro card
- `conference-1.jpg` … 3 — presenting / poster / with peers
- `travel-1.jpg` … 3     — places you've been
- `life-1.jpg` … 3       — hobbies, sport, everyday moments

Tips:
- Keep the long edge around 1200–1600 px and compress (JPG ~200–400 KB) so the page stays fast.
- In each card, swap the `data-src` path from `assets/images/empty_300x200.png` to your file above.
